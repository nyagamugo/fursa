# Fursa

A responsive, single-page marketing concept for Fursa and the Clean Start initiative.

## Preview

Open `index.html` in the in-app Browser canvas or a modern browser. No installation, server, or build step is required. Styles, scripts, fonts, and the original SVG illustration are local; there are no external dependencies.

## Interactions

- Navigation and hero links scroll to sections on the same page.
- FAQ entries expand using native HTML disclosures.
- “Find my first step” opens a keyboard-accessible reflection dialog with three personalized prompts, a reset action, and close/Escape support.
- Reflection answers are not saved, tracked, or submitted.
- The layout adapts to mobile and honors reduced-motion preferences.

## Content

The project name and Clean Start team/hackathon connection were supplied by the project owner. The private source documents were not accessible. All other positioning is draft concept copy; no product availability, verified features, team roles, or impact metrics are asserted. Update `index.html` with approved project details before publishing.

## Files

- `index.html`: page content and original illustration.
- `styles.css`: responsive visual design and motion.
- `app.js`: local reflection interaction.
